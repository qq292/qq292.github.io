# Плагин AnimToTextureGenerator Документация

---

### Описание

**AnimToTextureGenerator** — это плагин для Unreal Engine 5, который автоматически преобразует анимационные последовательности скелетной сетки в **текстуру вершинной анимации (Vertex Animation Texture, VAT)** и создаёт все связанные ассеты, включая статическую сетку, инстансы материалов и дата-ассеты. Плагин упрощает рабочий процесс VAT за счёт интеграции инструментов редактора и обеспечивает преобразование из анимации в текстуру одним нажатием.

Плагин поддерживает **Unreal Engine 5.4 — 5.8** и совместим с API UE 5.4-5.6 и UE 5.7+.

### Возможности

- **Генерация VAT одним нажатием** — преобразование анимационных последовательностей скелетной сетки в текстуру вершинной анимации одним нажатием.
- **Автоматическое создание статической сетки** — автоматическое создание статической сетки из скелетной для рендеринга VAT.
- **Управление инстансами материалов** — автоматическое клонирование и управление инстансами материалов с сохранением иерархии исходного материала.
- **Извлечение текстур костей** — извлечение текстур вращения, позиции и веса костей для хранения анимационных данных.
- **Выбор анимационных последовательностей** — встроенный диалог выбора с фильтром, отображающий только те анимации, которые совместимы с выбранной скелетной сеткой.
- **Поддержка LOD** — возможность выбора уровня детализации (LOD) для обработки при выборе анимации.
- **Проверка частоты дискретизации** — автоматическая проверка частоты дискретизации анимационных последовательностей с выдачей предупреждения при несоответствии (может вызывать подтормаживание анимации).
- **Интеграция с браузером контента** — добавление быстрого перехода в контекстное меню правой кнопки мыши, когда в браузере контента выбрана скелетная сетка.
- **Панель инструментов редактора скелетных сеток** — добавление кнопки на панель инструментов редактора скелетных сеток для быстрого доступа.
- **Совместимость с UE 5.4-5.8** — обеспечение совместимости от UE 5.4 до 5.8 с помощью условной компиляции, обработка изменений API между версиями.

### Системные требования

- **Unreal Engine** — 5.4, 5.5, 5.6, 5.7 или 5.8
- **IDE** — Visual Studio 2019 или новее (рекомендуется для C++ проектов)
- **Тип проекта** — только плагин редактора (не может быть запакетирован в рантайм)

### Установка

1. Клонируйте или скопируйте папку плагина в директорию `Plugins/` вашего проекта.
2. Если в проекте нет папки `Plugins`, создайте её в корне проекта.
3. Нажмите правой кнопкой мыши на файл `.uproject`, выберите **Generate Project Files** (или выполните `Setup.sh` / `GenerateProjectFiles.sh`).
4. Откройте проект в редакторе Unreal Engine.
5. Перейдите в **Edit > Plugins**, найдите **AnimToTextureGenerator** и активируйте его.
6. Если редактор предложит перезапуск, перезапустите его.

### Использование

#### Способ 1: Контекстное меню браузера контента

1. В **браузере контента (Content Browser)** выберите ассет **скелетной сетки (Skeletal Mesh)**.
2. Нажмите правой кнопкой мыши на выбранный ассет, чтобы открыть контекстное меню.
3. Нажмите **Convert Animations to Texture (VAT)**.
4. Появится диалог выбора директории — выберите путь сохранения и нажмите **Select Folder**.
5. Откроется диалог **выбора анимационных последовательностей**, в котором отображаются только анимации, совместимые с выбранной скелетной сеткой.
6. **Выберите несколько** анимационных последовательностей для преобразования.
7. В выпадающем списке **LOD** выберите уровень детализации для обработки.
8. Нажмите **Confirm Selection (Подтвердить выбор)**.
9. Если частоты дискретизации выбранных анимаций не совпадают, появится диалог предупреждения — нажмите **Yes** для продолжения или **No** для отмены.
10. Плагин выполнит обработку преобразования, по завершении появится уведомление об успехе.

#### Способ 2: Панель инструментов редактора скелетных сеток

1. Откройте **редактор скелетных сеток (Skeletal Mesh Editor)** с выбранной скелетной сеткой.
2. Нажмите кнопку **AnimToTextureGenerator** на панели инструментов редактора (иконка: класс Texture2D).
3. Следуйте шагам 4-10 способа 1.

#### Способ 3: Кнопка плагина (активная скелетная сетка)

1. Убедитесь, что в **редакторе скелетных сеток** открыта скелетная сетка (активный ассет).
2. Используйте кнопку плагина (доступна через панель инструментов или пользовательскую комбинацию клавиш).
3. Следуйте шагам 4-10 способа 1.

### Создаваемые ассеты

По завершении преобразования в выбранном пути сохранения будут созданы следующие ассеты:

| Тип ассета                                           | Описание                                                                                                                                                    |
| ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Статическая сетка (Static Mesh)**                  | Статическая сетка, полученная из скелетной, для рендеринга VAT.                                                                                             |
| **Корневой материал (Material)**                     | Корневой материал, содержащий узлы шейдера VAT для выборки текстуры анимации.                                                                               |
| **Инстанс материала (Material Instance)**            | Инстанс материала для каждого слота материала, подключённый к корневому материалу.                                                                          |
| **Дата-ассет (Data Asset)**                          | `UAnimToTextureDataAsset` — содержит ссылки на все созданные ассеты, анимационные последовательности, текстуры костей и информацию о частоте дискретизации. |
| **Текстура вращения костей (Bone Rotation Texture)** | Текстура для хранения данных анимации вращения костей.                                                                                                      |
| **Текстура позиции костей (Bone Position Texture)**  | Текстура для хранения данных анимации позиции костей.                                                                                                       |
| **Текстура веса костей (Bone Weight Texture)**       | Текстура для хранения данных анимации веса костей.                                                                                                          |

### API для блюпринтов

Плагин предоставляет следующие функции, вызываемые из блюпринтов, через `AnimToTextureGeneratorLibrary`:

| Функция                                     | Описание                                                                                                                                                                          |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OpenFilteredAnimSequencePicker`            | Открыть диалог выбора анимационных последовательностей с фильтром. Параметры: `FilterSkeletalMesh` (скелетная сетка для фильтрации), `OnAssetsPicked` (делегат обратного вызова). |
| `ShowSimpleSuccessToast`                    | Показать простое уведомление об успехе. Параметры: `Message` (отображаемый текст), `Duration` (длительность отображения, секунды).                                                |
| `InvokeConvertSkeletalMeshToStaticMesh`     | Преобразовать скелетную сетку в статическую. Параметры: `SkeletalMesh`, `NamePrefix`, `LODIndex`. Возвращаемое значение: `UStaticMesh*`.                                          |
| `InvokeAnimationToTexture`                  | Запустить основное преобразование анимации в текстуру. Параметры: `DataAsset`. Возвращаемое значение: `bool`.                                                                     |
| `InvokeSetLightMapIndex`                    | Установить индекс UV карты освещения для статической сетки. Параметры: `StaticMesh`, `LODIndex`, `LightmapIndex`, `bGenerateLightmapUVs`. Возвращаемое значение: `bool`.          |
| `InvokeUpdateMaterialInstanceFromDataAsset` | Обновить инстанс материала на основе дата-ассета. Параметры: `DataAsset`, `MaterialInstance`, `MaterialParameterAssociation`.                                                     |
| `FindActiveSkeletalMesh`                    | Найти активную скелетную сетку в редакторе. Возвращаемое значение: `USkeletalMesh*`.                                                                                              |

### Дата-ассет: UAnimToTextureDataAsset

`UAnimToTextureDataAsset` — это основная структура данных, хранящая всю информацию о созданном VAT:

| Свойство              | Тип                      | Описание                                                          |
| --------------------- | ------------------------ | ----------------------------------------------------------------- |
| `AnimSequences`       | `TArray<UAnimSequence*>` | Массив анимационных последовательностей, включённых в VAT.        |
| `SkeletalMesh`        | `USkeletalMesh*`         | Ссылка на исходную скелетную сетку.                               |
| `StaticMesh`          | `UStaticMesh*`           | Ссылка на созданную статическую сетку.                            |
| `BoneRotationTexture` | `UTexture2D*`            | Текстура анимации вращения костей.                                |
| `BonePositionTexture` | `UTexture2D*`            | Текстура анимации позиции костей.                                 |
| `BoneWeightTexture`   | `UTexture2D*`            | Текстура анимации веса костей.                                    |
| `SampleRate`          | `float`                  | Частота дискретизации кадров (дробное значение кадров в секунду). |
| `UVChannel`           | `int`                    | Индекс канала UV, используемого статической сеткой.               |

### Структура модулей

| Файл                                | Описание                                                                                                                                                                                              |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AnimToTextureGenerator.cpp`        | Точка входа основного модуля. Обработка запуска/остановки, регистрация кнопок панели инструментов, контекстного меню браузера контента и расширение панели инструментов редактора скелетных сеток.    |
| `AnimToTextureGeneratorLibrary.cpp` | Функции библиотеки, доступные из блюпринтов. Предоставляет вспомогательные функции для открытия выбора анимации, вызова преобразования, управления материалами и показа уведомлений.                  |
| `Processor.cpp`                     | Основная логика обработки. Координация полного процесса генерации VAT: создание статической сетки, извлечение текстур костей, клонирование материалов, создание инстансов материалов и генерация VAT. |
| `AnimSequencePicker.cpp`            | Элементы управления UI диалога выбора анимационных последовательностей на базе Slate. Предоставляет выбор ресурсов с фильтром и поддержкой уровней LOD.                                               |

### Совместимость версий

Плагин использует условную компиляцию для поддержки нескольких версий UE:

- **UE 5.4 - 5.6** — для внутренних вызовов функций используется `UAnimToTextureGeneratorLibrary`, для связи параметров материала — `LayerParameter`.
- **UE 5.7+** — для внутренних вызовов функций используется `UAnimToTextureBPLibrary`, для связи параметров материала — `GlobalParameter`.
